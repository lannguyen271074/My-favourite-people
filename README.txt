MY HUSBANDS — MEMORY ARCHIVE

1. Tạo repository trên GitHub với tên: My-Husbands
   Lưu ý: GitHub không cho phép khoảng trắng trong tên repository; vì vậy dùng My-Husbands.

2. Upload toàn bộ nội dung trong thư mục idol_archive lên repository, gồm:
   - index.html
   - style.css
   - script.js
   - thư mục assets

3. Để nhạc nền phát bài BTS — 2.0:
   - Đặt file âm thanh bạn có quyền sử dụng vào thư mục assets.
   - Đổi tên chính xác thành: 2.0.mp3
   - Code đã được cài để bắt đầu phát nhạc khi người xem bấm CLICK TO OPEN.
   - Không nên tự động phát ngay khi mở trang vì trình duyệt thường chặn autoplay có âm thanh.

4. Bật GitHub Pages:
   Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

5. URL dự kiến:
  https://lannguyen271074.github.io/My-favourite-people/

Lưu ý bản quyền:
Website không kèm sẵn file nhạc BTS — 2.0. Bạn cần tự thêm file âm thanh mà bạn có quyền sử dụng.
